# نقشهٔ اجرا و وضعیت واقعی

مرجع نسخهٔ جاری: [CURRENT_RELEASE](CURRENT_RELEASE.md). راهنمای سورس: [CODE_GUIDE.fa](CODE_GUIDE.fa.md). این فهرست جای چک‌لیست‌های تاریخی برش‌های اولیه را می‌گیرد؛ ADRها تاریخچهٔ تصمیم را نگه می‌دارند.

## ورودی و آمادگی

- [x] ورودی عمومی فارسی، موبایل و دو تم با پرسش‌های رایج و توضیح صریح محدودیت‌ها؛ بدون سرویس/بستهٔ تازه.

## پایه، هویت و سازمان

- [x] Git/GitHub، TypeScript strict، Next.js، فونت محلی، دو تم و RTL.
- [x] هویت واقعی، رمز hash‌شده، نشست DB، مدیریت و لغو نشست.
- [x] حذف کدساز/MFA از حساب معمولی به درخواست مالک؛ پاک‌سازی وضعیت قدیمی با migration 0005.
- [x] سازمان مدرسه/شرکت/شخص، عضویت، نقش و تعلیق؛ FORCE RLS و runtime غیرمالک.
- [x] دعوت ایمیلی زمان‌دار/یک‌بارمصرف با اثبات ایمیل؛ لینک اتاق محدود با حساب واردشده.
- [x] ثبت‌نام موقت بدون فرستنده و بدون ادعای emailVerified؛ بازیابی بدون فرستنده مسدود.
- [x] adapter SMTP با TLS و فرستندهٔ خارجی اختیاری.
- [ ] تحویل ایمیل با دامنهٔ واقعی، خروج از حالت موقت و آزمون بازیابی عمومی.
- [ ] ترم، درس، enrollment، تکلیف، مدیریت ثبت‌نام آموزشی و انتقال مالکیت.

## اتاق و همکاری

- [x] اتاق و میزبان پایدار، شروع/قفل/پایان، ACL و audit.
- [x] چت persist، clientId برای retry، moderation و نمایش متن امن.
- [x] تختهٔ مشترک persist، snapshot، revision، undo/clear و دانلود SVG.
- [x] حضور وب، hand raise، مجوز ده‌دقیقه‌ای، لغو و ban.
- [x] join API با نشست، role تازه، توکن کوتاه و grant محدود.
- [x] SDK واقعی دریافت/انتشار صوت و دوربین و اشتراک صفحه؛ consent، پاک‌سازی خروج، کیفیت خودکار و reconnect.
- [x] gateway خودمیزبان: کنترل هر handshake/reconnect و reauthorization اتصال برقرار.
- [x] دریافت واقعی تصویر/صدا بین دو مرورگر با SFU محلی؛ رد reconnect توکن banشده و حذف participant آزموده می‌شوند.
- [ ] استقرار SFU/TURN عمومی و آزمون موبایل/ISP واقعی ایران، قطع/وصل و تمدید مجوز طولانی.
- [x] بررسی پیش از کلاس: انتخاب دوربین/میکروفون، پیش‌نمایش، سطح ورودی و تست صدای خروجی؛ حفظ انتخاب در حافظهٔ تب برای اتصال رضایتی اتاق.
- [ ] انتخاب خروجی صوت در مرورگرهای پشتیبان و پذیرش پیش‌ورود روی سخت‌افزار و Safari واقعی.
- [ ] چندصفحه/متن/فایل تخته و همگام‌سازی کم‌تأخیر در صورت نیاز اندازه‌گیری‌شده.
- [ ] گزارش حضور و غیاب قابل اتکا از رویدادهای واقعی رسانه.

## مدیریت و تجربهٔ کاربری

- [x] اتاق سادهٔ دسکتاپ با تختهٔ بزرگ و ستون راست، چهار تب موبایل و بزرگ‌نمایی رسانه.
- [x] گلس محدود، خاموشی جلوه‌ها، reduced motion، تم روشن/تیره.
- [x] مرکز نظارت واقعی سازمان، میزبان اتاق، حضور وب، اعضا، تیکت‌ها و مشخصات فرایند وب.
- [x] برند مجموعه با نام/رنگ preset/پیام پایدار و دسترسی مدیریتی همان مجموعه.
- [x] تیکت خصوصی عضو، شماره، پاسخ و بستن توسط مدیر همان مجموعه.
- [ ] پیوست تیکت، اعلان، گزارش عملیاتی و support پلتفرم با فرایند مجزای مجاز.
- [ ] telemetry خصوصی SFU و ظرفیت باقی‌مانده بر اساس سقف enforce‌شده و مصرف واقعی.

## دو حالت استقرار و فروش

- [x] یک سورس/image با پروفایل normal/domestic و allowlist میزبان‌های حالت داخلی.
- [x] وب مستقل، PG، migration و gateway جدا از runtime وب؛ Compose رسانه و قالب TLS proxy.
- [x] اسکریپت بسته‌بندی image موجود، سورس commit و checksum؛ بدون pull و بدون secret.
- [x] آزمون PostgreSQL دو سازمان و E2E همکاری در موبایل/دسکتاپ.
- [ ] ساخت/اجرای image لینوکس روی Docker واقعی و restore روی مقصد؛ daemon این دستگاه در دسترس نیست.
- [ ] تمرین شروع سرد و تماس از دو شبکه با مسدودبودن egress بین‌المللی.
- [ ] backup/restore، RPO/RTO، DNS/TLS داخلی و طرح انتقال سایت مرجع نوشتن.
- [ ] load/network test، سهمیه/تعرفه/صورتحساب و ظرفیت ضبط/پهنای باند.
- [ ] بررسی امنیت مستقل، CSP متناسب با رسانه، incident runbook و سیاست حریم خصوصی.
