# ADR 0004 — ورودی عمومی بدون دادهٔ نمونه و PostgreSQL مدیریت‌شده

تاریخ: 2026-10-13. وضعیت: پذیرفته‌شده؛ آماده‌بودن کل محصول تابع ROADMAP است.

## مسئله و تصمیم

کاربر نسخهٔ واقعی برای آزمون چند دستگاه می‌خواهد و حذف دمو از نسخهٔ عمومی را صریحاً درخواست کرده است. نبود زیرساخت نباید اشخاص، کلاس‌ها یا تعداد حضور مصنوعی را جایگزین کند. ورودی عمومی به workspace واقعی می‌رود؛ نشست نامعتبر به ورود هدایت می‌شود. مسیرهای demo در production و Vercel برابر 404 هستند. مسیرهای قدیمی اعضا/پشتیبانی به workspace و تنظیمات به امنیت حساب می‌روند؛ این redirect به معنی تکمیل پشتیبانی نیست. مرکز نظارت، SSR خصوصی با نشست، عضویت مدیریتی و MFA تازه دارد؛ نام اتاق‌ها و شمار اعضای فعال را از همان سازمان و مشخصات وب را از اجرای واقعی می‌خواند. حضور و ظرفیت رسانه تا اتصال SFU مقدار ساختگی ندارند.

رابط قدیمی فقط برای regression محلی، با development، نبود VERCEL و flag صریح HAMYAR_LOCAL_DEMOS اجرا می‌شود. flag حتی اگر در Vercel تنظیم شود اجازهٔ نمایش fixture نمی‌دهد. لینک عمومی به دمو باقی نمی‌ماند. تست production از fixture محلی جداست.

Neon Free در region iad1 برای دیتابیس اختصاصی hamyar-production ایجاد شد. کاربر ساخت کلیدهای خصوصی و ثبت آنها در Vercel را اجازه داد. migration با اتصال مستقیم مالک و runtime با اتصال pooled نقش hamyar_app انجام می‌شود. نقش برنامه نه مالک است، نه superuser و نه bypass و عضویت نقش مالک ندارد. TLS از verify-full استفاده می‌کند.

اتصال Marketplace برای دریافت credential مالک موقت بود. sync پس از migration قطع شد تا کلید مالک در runtime وب باقی نماند؛ resource حذف نشده است. DATABASE_URL برنامه مستقل، همراه کلید نشست خصوصی، در Vercel ثبت است. اتصال مالک فقط در تنظیم اپراتور خارج از Git نگهداری می‌شود. preview به DB تولید متصل نشده است.

## اتاق‌های پایدار

meeting_room و room_assignment با foreign key مرکب سازمانی و FORCE RLS افزوده شدند. فهرست عضو فقط اتاق تخصیص‌یافته را می‌خواند؛ مدیر با MFA اتاق و میزبان فعال می‌سازد. نقش اتاق از رکورد سرور ساخته می‌شود. تخصیص فقط پیش از شروع مجاز است تا تغییر role برقرار بدون UpdateParticipant ادعا نشود. وضعیت open در DB به معنی حضور یا سلامت SFU نیست. endpoint عمومی join و کنترل رسانهٔ برقرار هنوز فعال نشده‌اند.

## محدودیت و هزینه

پلن رایگان ظرفیت نامحدود یا SLA تضمین نمی‌کند. حساب LiveKit Cloud و env آن نیازمند مرحلهٔ کاربر است. دامنهٔ ایمیل فعلاً موجود نیست؛ signup/reset عمومی تا فرستندهٔ معتبر غیرفعال‌اند. RLS و نشست آماده‌اند، اما نبود رسانه، ضبط، تختهٔ مشترک، مدل تحصیلی و تیکت مانع اعلام نسخهٔ کامل است. دادهٔ آزمون فقط در DB جداگانهٔ _test وارد می‌شود؛ production با fixture seed نشده است.

## آزمون و بازگشت

آزمون‌های منفی tenant برای اتاق، میزبان/assignment خارجی، member بدون مجوز، اتاق بسته/پایان‌یافته و query بدون context اجرا می‌شوند. E2E تولید ثابت می‌کند flag محلی در Vercel نیز دمو را برنمی‌گرداند. برگشت UI با commit قبلی ممکن است؛ migration افزایشی است و rollback UI نباید جدول یا حساب واقعی را حذف کند.
