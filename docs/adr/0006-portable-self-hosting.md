# ADR 0006 — استقرار قابل انتقال و آمادگی شبکهٔ داخلی ایران

تاریخ: 2026-10-13 — وضعیت: پذیرفته.

## نیاز و تصمیم

مالک می‌خواهد فعلاً از Vercel برای آزمایش استفاده کند، در وضعیت عادی سرور مستقل داشته باشد و هنگام قطع دسترسی بین‌المللی، همیار را روی VPS ایران اجرا کند. بنابراین سرویس SaaS خارجی شرط کارکرد اصلی محصول نیست. LiveKit Cloud اختیاری است؛ LiveKit متن‌باز، PostgreSQL، Redis و در آینده Egress و ذخیره‌سازی خصوصی روی زیرساخت خود همیار اجرا می‌شوند.

سورس و schema مشترک‌اند و تنظیمات میزبان هنگام اجرا تعیین می‌شوند. `HAMYAR_STANDALONE=1` در build لینوکس خروجی مستقل Next.js می‌سازد. image وب با کاربر غیرroot اجرا می‌شود؛ migration image و credential نقش hamyar_schema از runtime نقش hamyar_app جداست. Compose جدید تنها برش فعلی حساب/سازمان/اتاق پایدار را استقرار می‌دهد؛ اتصال رسانه، ضبط و تخته را آماده اعلام نمی‌کند. تنظیمات خصوصی در Git، Docker build context و upload ورسل نیستند.

## وابستگی و انتقال

حالت آمادهٔ داخلی باید پیش از قطعی، imageهای نسخه‌دار، فایل‌ها، backup آزمودهٔ DB، DNS و گواهی معتبر را در ایران داشته باشد. اجرای runtime نباید نصب npm، کشیدن image، صدور گواهی از سرویس خارجی، OAuth خارجی، CDN یا STUN خارجی بخواهد. قالب رسانه IP مشخص و STUN داخلی می‌خواهد؛ NAT و TURN/TLS روی ISPهای هدف باید آزموده شوند.

یک محیط مرجع برای نوشتن داده داریم. دو DB مستقل قابل‌نوشتن را خودکار با هم ادغام نمی‌کنیم. انتقال اولیه با توقف نوشتن، backup/restore و اعتبارسنجی انجام می‌شود. برای آماده‌باش آینده replication، RPO/RTO، انتقال فایل، جلوگیری از split-brain و فرایند failback جداگانه طراحی و آزموده شوند. قطعی اینترنت نمی‌تواند دادهٔ خارج را پس از قطعی به داخل منتقل کند.

ورسل و Neon فعلی فقط محیط آزمایش عمومی باقی می‌مانند؛ دادهٔ آن‌ها در این تغییر منتقل نمی‌شود. کلیدها بین محیط‌ها مستقل‌اند؛ تغییر origin/کلید نشست ورود مجدد می‌خواهد. MFA و RLS در همهٔ محیط‌ها یکسان‌اند. SMTP/فرستندهٔ داخلی هنوز پیاده نشده؛ ثبت‌نام موقت بدون تأیید ایمیل محدودیت ADR 0005 را دارد.

## مرز پذیرش

Docker image و Compose پایه، شروع قابلیت انتقال‌اند. تضمین کارکرد در اینترنت ملی نیازمند آزمون واقعی قطع egress بین‌المللی، DNS/TLS داخلی، شبکهٔ چند دستگاه، restore، کنترل ban هنگام reconnect و ادامهٔ ضبط است. [راهنمای خودمیزبانی](../SELF_HOSTING.md) مراحل و وضعیت فعلی را ثبت می‌کند.
