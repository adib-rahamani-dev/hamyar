# ADR 0007 — حذف مرحلهٔ کدساز و ورود با رمز

تاریخ: 2026-10-14 — پذیرفته با درخواست صریح مالک برای حذف تأیید چندمرحله‌ای.

## تصمیم جاری

تأیید دومرحله‌ای مبتنی بر برنامهٔ کدساز از حساب حذف می‌شود: plugin سرور/کلاینت، صفحهٔ کد، فرم فعال‌سازی و شرط MFA برای مدیریت حذف‌اند. ثبت‌نام، ورود، ساخت مجموعه، پذیرش دعوت نقش مدیریتی و پنل نظارت با نشست معتبر و رمز انجام می‌شوند. الزام قبلی عمومی مدیران در ADR 0003 و MFA در توضیحات تاریخی با این تصمیم جایگزین می‌شود.

حساب‌های قبلی نیز در صفحهٔ کد گیر نمی‌کنند. migration 0005 پرچم قدیمی، proof قدیمی و secret/backup codeهای TOTP را پاک می‌کند؛ حساب‌ها و نشست‌ها حذف نمی‌شوند. ستون‌ها و جدول قدیمی برای سازگاری schema باقی می‌مانند و API آن قابلیت غیرفعال است. نسخهٔ اولیهٔ اختیاری جای خود را به حذف کامل مرحله می‌دهد.

RLS، تعیین نقش/سازمان از نشست و عضویت تازه، Origin، hash رمز، محدودیت درخواست و لغو نشست برقرارند. دادهٔ ایمیل تأییدنشده دسترسی دعوت نمی‌گیرد و recovery بدون فرستنده غیرفعال می‌ماند. حفاظت در برابر سرقت رمز کاهش می‌یابد؛ این انتخاب صریح مالک برای ساده‌شدن تجربه است. دسترسی اضطراری پلتفرم سیاست مستقل MFA دارد و هنوز پیاده نشده است.

## آزمون

ورود/ثبت‌نام با رمز → مجموعه/اتاق/نظارت → خروج و ورود مجدد، روی مرورگر موبایل و دسکتاپ. legacy flag/secret موجب چالش ورود نمی‌شود؛ migration آن‌ها را پاک می‌کند، endpoint و صفحهٔ کد قابل استفاده نیستند و فرد خارج سازمان همچنان رد می‌شود. آزمون‌ها فقط در دیتابیس مستقل با دادهٔ مصنوعی اجرا می‌شوند.
